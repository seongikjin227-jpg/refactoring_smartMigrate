# 발표 자료 디자인

## 방향
Taste Skill이 제시한 The well-kept board(dense-tiles), seed 378759576. 실제 매핑·SQL·Agent 책임을 면 단위로 배치한다. 설명 문서이므로 사진과 자동 움직임 대신 아키텍처 연결, SQL 비교, 검증 표가 주된 시각 자료다. 사용자가 지정한 슬라이드형 문서와 아키텍처 중심 구성이 랜딩 페이지 관례에 우선한다.

## 토큰
- 배경 #f3f4f1, 본문 #1d2724, 정보 면 #e3e7e2.
- 강조 #b8ebce, 주요 구조 #203d32, 역상 본문 #f5fff8.
- 간격 12px, 페이지 여백 clamp(24px,4.4vw,72px), 모바일 20px.
- 본문 16–21px, 주제목 30–50px, 표지 46–88px.
- 한글 오프라인 문서용 Malgun Gothic / Apple SD Gothic Neo. 원본 방향의 Jost·사진·marquee는 한글 발표 문서의 요구에 맞춰 적용하지 않는다.
- 직각 모서리, 평면 배경, 정지 화면 그림자 없음.
- 모바일 표·주석 최소 13px. 큰 화면 발표를 기본으로 하며 모바일에서는 확대·세로 스크롤 가능.
- 키보드 포커스는 3px 윤곽선, 버튼 피드백은 140ms. reduced-motion에서는 전환 제거.
- 발표 노트 배경 #dae4f1, 본문 #20324e. 인쇄는 A4 가로·10mm 여백, 노트 제외.

## 조작
좌우 키·PageUp/Down·버튼으로 이동, Home/End로 처음·마지막 이동. N은 노트, O는 전체 보기. 화면별 고정 높이로 내용을 자르지 않는다. 모바일의 긴 장은 스크롤하고 하단 탐색은 문서 흐름에 둔다. 인쇄에서는 11장을 모두 출력한다.

## 검증 기준
1440, 768, 390px의 11장 전체 화면, 가로 넘침·노트·전체 보기·키보드·인쇄를 확인한다. 마케팅용 검사기의 사진·자동 움직임 요구는 발표 문서에 적용하지 않는다. 키보드 조작은 즉시 반응하며 reduced-motion을 지원한다.
