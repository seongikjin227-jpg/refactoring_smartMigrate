### MAP_ID 1 생성 SQL

**MIG_SQL**

```sql
MERGE INTO TOBE_HR_DEPT T USING (SELECT * FROM ASIS_HR_DEPT) S ON (T.DEPT_ID = S.DEPARTMENT_ID) WHEN MATCHED THEN UPDATE SET T.DEPT_NAME = S.DEPARTMENT_NAME WHEN NOT MATCHED THEN INSERT (DEPT_ID, DEPT_NAME) VALUES (S.DEPARTMENT_ID, S.DEPARTMENT_NAME)
```

**VERIFY_SQL**

```sql
-- 참고 SQL: Oracle 미실행. 실제 DDL 자료형/NLS에 맞춘 변환 검토 필요.
WITH ASIS_DATA AS (
  SELECT S.DEPARTMENT_ID AS DEPT_ID, S.DEPARTMENT_NAME AS DEPT_NAME FROM ASIS_HR_DEPT S
), TOBE_SCOPE AS (
  SELECT T.* FROM TOBE_HR_DEPT T WHERE EXISTS (SELECT 1 FROM ASIS_DATA A WHERE A.DEPT_ID = T.DEPT_ID)
), ASIS_COUNTS AS (SELECT COUNT(*) AS ROW_CNT, COUNT(DEPT_ID) AS C0, COUNT(DEPT_NAME) AS C1 FROM ASIS_DATA), TOBE_COUNTS AS (SELECT COUNT(*) AS ROW_CNT, COUNT(DEPT_ID) AS C0, COUNT(DEPT_NAME) AS C1 FROM TOBE_SCOPE)
SELECT A.ROW_CNT AS ASIS_CNT, T.ROW_CNT AS TOBE_CNT,
  CASE WHEN A.ROW_CNT = T.ROW_CNT AND A.C0 = T.C0 AND A.C1 = T.C1 THEN 'PASS' ELSE 'FAIL' END AS COUNT_RESULT
FROM ASIS_COUNTS A CROSS JOIN TOBE_COUNTS T
```
